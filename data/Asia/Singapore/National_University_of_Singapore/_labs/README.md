# National University of Singapore - Labs

本目录用于存放 National University of Singapore 跨专业共享的重点实验室、研究中心和研究组介绍。

## 文件命名

实验室文件建议使用以下格式：

```text
Lab_Name.md
```

示例：

- `NExT_Lab.md`
- `NUS_Artificial_Intelligence_Laboratory.md`
- `NUS_Database_Group.md`

## 专业文件引用方式

同一学校目录下的专业文件可以使用相对路径引用实验室文件：

```markdown
- **相关实验室**： [NExT Lab](_labs/NExT_Lab.md)
```

## 建议字段

每个实验室介绍文件建议包含：

- **实验室名称**： 
- **所属院系**： 
- **研究方向**： 
- **核心教授**： 
- **主页链接**： 
- **相关项目**： 
- **最后核实日期**： YYYY-MM-DD
