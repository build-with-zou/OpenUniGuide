# CyLab Security and Privacy Institute

## 基础信息

- **所属学校**： Carnegie Mellon University
- **所属院系**： University-wide security and privacy institute；与 Computer Science Department、Software and Societal Systems Department、Electrical and Computer Engineering 等多个单位相关
- **实验室/研究中心名称**： CyLab Security and Privacy Institute
- **主页链接**： https://www.cylab.cmu.edu/

## 研究方向

- **方向 1**： Security and privacy
- **方向 2**： Secure systems
- **方向 3**： System and network security
- **方向 4**： Cryptographic protocols
- **方向 5**： Language-based security
- **方向 6**： Secure information flow
- **方向 7**： Accountability and transparency
