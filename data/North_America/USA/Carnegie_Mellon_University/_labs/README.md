# Carnegie Mellon University - Labs

本目录用于存放 Carnegie Mellon University 跨专业共享的重点实验室、研究中心和研究组介绍。

## 文件命名

实验室文件建议使用以下格式：

```text
Lab_Name.md
```

示例：

- `Carnegie_Mellon_Database_Group.md`
- `Carnegie_Mellon_Neuroscience_Institute.md`
- `Center_for_the_Neural_Basis_of_Cognition.md`
- `Principles_of_Programming_Group.md`
- `CyLab_Security_and_Privacy_Institute.md`

## 专业文件引用方式

同一学校目录下的专业文件可以使用相对路径引用实验室文件：

```markdown
- **相关实验室**： [Carnegie Mellon Database Group](_labs/Carnegie_Mellon_Database_Group.md)
```
