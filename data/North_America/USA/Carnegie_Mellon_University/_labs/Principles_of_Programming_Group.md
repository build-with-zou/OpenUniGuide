# Principles of Programming Group

## 基础信息

- **所属学校**： Carnegie Mellon University
- **所属院系**： Computer Science Department, School of Computer Science
- **实验室/研究组名称**： Principles of Programming Group
- **主页链接**： https://www.cs.cmu.edu/~pop/

## 研究方向

- **方向 1**： Programming languages
- **方向 2**： Logic
- **方向 3**： Formal semantics and type theory
- **方向 4**： Programming language design and implementation
- **方向 5**： Formal specification and verification of hardware and software systems
- **方向 6**： Quantum computing
- **方向 7**： Probabilistic programming
